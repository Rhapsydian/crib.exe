## Problem-solving notes

- **The coach missed skipped steps:** it watched only the replay's
  current step, so a skip (or a new play cutting the replay short) hid
  turns and Hooks. It now reads every step as it appears.
- **The seed search found every seed identical:** `TUTORIAL_OPTIONS`
  carries its own seed, and the script spread it last.
- **Browser playthroughs:** a page-script driver plays the tutorial by
  following the Cribbage coach's own suggestions. The pane must be in
  front, or timers throttle and fights crawl.
- **The end screen without playing a run:** in dev, Vite serves
  `/src/engine/run.ts`, so a simulated result can be dropped into
  `window.__run.pause`.
- **I committed the colon change without running the suite**; one coach
  test quoted the old text. Fixed in `f91020e`. Again in checkpoint 3: a
  `check | tail -1 && ...` chain committed with type errors (tail's exit
  code hid them); fixed in `db95d06`. Read the check's result before
  committing.
- **A failed evasion ended the run before the gatekeeper's encounter was
  logged**; an existing R8 test caught it (the last encounter was an
  elite).
- **AI answers in tests draw their own generator**: the game's AI-noise
  stream is shared, so a fallback answer drawn from it can't be replayed
  from a save (as with fights).
- **Reaching an evasion in the browser:** drive a `LiveRun` in the page
  (dev imports) to the pause, store its save, resume from the menu.
