# Session 11 — 2026-08-23

`/decision-session`, designing the class-starting-passives idea banked
in session 8: each of the 6 classes gets a distinct, mild, permanent
passive from the start (StS-class-relic equivalent), one specifically
meant to help Ghost's damage-access gap.

Confirmed in one round, no revisions — all 6 tied directly to each
class's session 8 identity:

- **Breacher — Foothold**: first time Control/Breach crosses to your
  favor each fight, gain a small extra push. Reinforces hit-then-hold.
- **Blackhat — Zero Day**: first Heat-costing Exploit subroutine each
  combat is free. Smooths entry into the reckless identity.
- **Saboteur — Sleeper Cell**: first Malware debuff each combat also
  advances a Root subroutine's condition. Models corrupt-and-manipulate
  as a literal link.
- **Operator — Primed**: first Root subroutine fired each combat reduces
  the next Exploit subroutine's trigger threshold. Jumpstarts the
  class's own signature combo.
- **Warden — Feedback Loop**: Encryption HoT also ticks a small Malware
  DoT onto the enemy. Heal-and-hurt in one motion.
- **Ghost — Return to Sender**: a portion of Encryption's counter-push
  carries through past center into enemy territory.

Five of six are mild tempo/consistency nudges; Ghost's is doing real
structural work rather than just flavor — instead of granting off-class
Exploit/Malware access, it makes Ghost's own defensive toolkit double as
offense, directly answering the damage-access gap flagged when Ghost was
introduced (session 8), complementary to the off-class reward-pool access
Ghost already has from session 7.
