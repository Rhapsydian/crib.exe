## Decisions (user, live; docs/design/meta-progression.md MP1-MP17)

- **MP1** onboarding, long-term goals and incremental power; the balance
  targets describe a fresh player, upgrades on top.
- **MP2** classes unlock by beating the first gatekeeper with the class
  before; **MP4** order Blackhat → Breacher → Operator → Warden → Eidolon
  → Wraith; **MP6** a steep Rep fallback for the next class.
- **MP3** Rep by depth (a caught layer at 75%), elites, victory; a
  one-time tutorial grant.
- **MP5 / MP12** testing switches `?unlockall` and `?resetprofile`,
  **REMOVE BEFORE RELEASE**; no refunds; export/import waits for a
  settings menu.
- **MP7** upgrade tracks (the user added fight Heat and archetype
  power); **MP8** the library (the user's design: one per archetype, all
  commons before uncommons before rares, a 4th starter added, not
  swapped); **MP9** starting common Burners.
- **MP11** pacing; then **option A** (the user: ~90% victory by run 20
  was too quick): the strongest tracks climb steeply.
- **MP13-MP15** ascension, named **Security Level** ("SEC 7"): ten
  levels, global unlocks, +15% Rep a level, a stacking ladder; the user
  added a Heat step, gauge offsets at 2/5/8, and kept the upgrade sizes
  (a maxed player may stomp level 0; the levels claw it back). Level 10
  all but impossible is fine.
- **MP16** the store is the **Message Board** (the user's name), hidden
  until a first finished run, introduced once.
- **MP17** a toggle to play without upgrades or starting picks.
