## Problem-solving notes

- **Kit power can't price a Mod that acts on the opponent's gain** (No Way
  In, Null Session): the single flat-Credit reference is neutralised, so
  the duel never ties. Those were priced only in stage 2, which is where
  every gatekeeper is tuned anyway.
- **Trace pressure multiplies with fire frequency:** ½ a fire on pieces
  that fire on turns *and* immediately gave 20 Trace a fight. ⅛ gave 5.
  Extra Trace is measured with versus without the pressure, so the
  player's own noise cancels out.
- **Pass rate moves ~1 point per 0.01 of gatekeeper scale:** two rounds
  of interpolation plus a nudge landed all eight.
- **Overwrote `scripts/enemy-check.ts` by mistake** (it already existed);
  restored it from git, and the new script is `roster-check.ts`.
- Two inline Python heredocs failed on shell quoting; writing the script
  to a scratch file and running it fixed both.
- A Trace-writing pool piece (Jackpot) on a gatekeeper broke the standing
  "Trace is player-only" test; swapped for Credential Stuffing.
- A victory test hit a 7-piece loadout: Backdoor Access's Mod-granted
  piece, always-slotted by design. The cap check now excludes
  Mod-granted pieces.
