## Notable problem-solving notes

- The crash-then-reverse arc here is a good example of why a sweep is
  worth running before assuming a hypothesis: the *bug* it surfaced
  (layer-1 Elites unreachable) turned out to matter more to the user
  than the original quarantine question, and the fix direction the code
  suggested (suppress the node type) was the wrong one design-wise once
  a human looked at it. Worth remembering: an engine crash discovered
  mid-investigation is a real design decision point, not just a bug to
  patch reflexively — flag it rather than silently picking the
  minimal-diff fix.
- The final sweep numbers held up qualitatively across both the
  workaround and the real-content versions (quarantine share still drops
  under `explore`, victory rate still roughly flat-to-down, Blackhat
  still collapses hardest) — the underlying finding wasn't an artifact
  of the temporary workaround, which is some independent confirmation
  it's real.
