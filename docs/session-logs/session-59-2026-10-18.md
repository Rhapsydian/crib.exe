## Problem-solving notes

- **Overwrote existing engine code.** Writing `basic-cribbage.ts` as
  "new" replaced the session-39 Cribbage driver -- the code the user has
  twice asked never to lose. Caught within minutes (the skill-retention
  check stopped compiling), restored from git, and the new game added
  beside it. Lesson: check a file exists before creating it.
- **Lessons can't teach wrong counts:** tests check every count against
  the engine; they caught three wrong totals in the first draft.
- **"Good play" on bad plays:** the first coach only knew two traps;
  judging each play as points less the opponent's expected reply (over
  the cards they could hold, given how many they have left) fixed it,
  and making the hint follow the same judgement keeps the two from
  disagreeing.

  the exact table changed discards everywhere (the coach now splits
  fives on its own crib when that's better), so the roguelite was
  re-tuned.
