# Session 12 — 2026-08-23

`/decision-session`, creating the first concrete named subroutines in
the game: each of the 6 classes' starting loadout, repeatedly flagged as
blocked on this since session 8.

Opened with a proposal of 4 subroutines per loadout (2 per specialized
archetype), 24 total. The user pushed back live: that structure leaves
only 2-3 open slots toward the floated ~6-slot cap, meaning near-
immediate forced swap-outs and little room for early-run acquisition to
matter. Revised to **1 per archetype + 1 thematic Cantrip = 3 per
loadout**, 18 total — kept the stronger half of the original draft per
archetype slot, added 6 new Cantrips (all tagged Daemon, per session 10's
own definition of that tag).

Review caught three things worth fixing before finalizing:

- **Session Lock** (Breacher's Encryption piece) originally triggered on
  "Heat above threshold" — a real problem specifically because Breacher
  is the *introductory* class: it would sit dead until Heat built up, bad
  onboarding for one of only 3 starting pieces. Changed to "dealer this
  hand," live from turn one.
- **Redundant Systems** (Warden) has the identical buildup-delay shape,
  but was kept as-is — being behind and grinding back is Warden's actual
  theme, and it's not the class new players see first.
- **Low Profile** (Ghost's Cantrip, guaranteed Heat reduction every turn)
  needed a floor: unbounded, Ghost's own identity (long, patient, grindy
  fights = many turns = many guaranteed fires) means a Ghost player could
  eventually neutralize Heat pressure entirely just by grinding —
  undermining the resource specifically for the class most likely to
  rely on long fights.
- One late naming fix: **Creeping Rot** (Warden's Malware DoT) renamed to
  **Memory Leak** — same effect, but the original name read as fantasy-
  genre rather than cyberpunk. Memory Leak is a real computing term for
  exactly this shape of problem (small, steady, background drain that
  compounds unnoticed).
