## Problem-solving notes

- **Calibrate by replay:** full runs per trial were too slow; capturing
  the player at each elite fight and replaying those fights gave real
  per-layer strength in ~40 seconds a trial.
- **Fights shorten with depth:** the player outgrows a fixed Breach gauge,
  so gauge size had to scale by layer alongside enemy strength.
- **A latent bug surfaced by balance:** the ejection rule had never been
  exercised because players never lost elites.
- **Wording:** "elites winning" read as the elites' wins; report "players
  win X%".
- **The timeline module imports Svelte**, so scripts using it run in the
  browser (dev-server console) rather than under tsx.
