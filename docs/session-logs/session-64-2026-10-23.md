## Decisions (user, live; docs/burners-events-design.md BE1-BE10)

- **Order:** Burners, then Events (of the content pass's four pieces).
- **BE1 combat Burners:** a mix: lumps resized to be worth a slot,
  rule-benders, and **temporary subroutines** (the user's category).
- **BE2 timing:** each Burner says when it acts. "Now" acts when armed and
  can be toggled off until your next discard or card (the user's
  refinement); "Next turn" at the start of your next turn. One armed at a
  time; all always shown in the arm row.
- **BE3 temporary subroutines:** an extra slot, top or bottom, one at a
  time, counting down; the name carries the burner glyph and a "Burner · N
  left" tag sits where a rank would go (the user: the icon once).
- **BE4 map Burners are Heat tools**, plus **Tunnel** (the user: pass
  through a Shop or Safehouse without spending it). Recon Ping retired.
  Skeleton Key flagged: the user is rarely contained outside gatekeepers,
  a symptom for the enemy pass.
- **BE5 contraband:** Event-only Burners; Events can also grant
  general-pool ones.
- **BE6:** carry limit stays 3; more Burner slots is a meta-progression
  idea.
- **BE7 the slate:** 24 Burners (with the user's wording).
- **Player-text rule (the user):** never "your" for the network's things:
  "the next gatekeeper's Heat toll", never "your next gatekeeper".
- **BE8-BE9 Events:** a library of ~30, growing across sessions (the
  game's story moments: pitfalls, steep bargains, gambles, games,
  double-edged pieces, class Mod upgrades); this session the first ten that
  need no new mechanics; Mods and class Mod upgrades next, mini-games after.
- **BE10:** every Event has story: a scene and a line per outcome.
- **Tuning:** the user approved the measured changes; Zero-Day lasts 4
  hands; contraband left at ~2x.
- **Balance stance (the user):** testers new to Cribbage find the game too
  hard, so rising win rates are welcome; report shifts.
- **Branch:** `content-pass` for this work; `playable` stays the demo.

## Problem-solving notes

- **One turn per hand:** a 12-point initiative bar gives about one turn a
  hand, so "the rest of the hand" is one turn; Zero-Day needed 4 hands.
- **The simulated player's timing** made Suppress Burners look worthless
  (fired at 0 Containment) and Warden look Burner-proof (spent in easy
  regulars, none left for gatekeepers). Fixed by teaching it to wait and
  to save.
- **Pinned-seed tests break with content:** the evasion test now searches
  for a run that reaches an evasion.
- **Committed a broken file again** (`0ac569a`: an unescaped apostrophe);
  fixed in `a787a38`. Shell-written quoting in TS strings is the trap; use
  the edit tool for text with apostrophes, and read `npm run check`'s
  result before committing.
- **A stale dev-console import** (Vite caches the un-timestamped module)
  showed an old Event list; a full reload fixes it.
