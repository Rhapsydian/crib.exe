## Problem-solving notes

- **Simulation speed was guarded at every engine change** with
  `scripts/engine-bench.ts`, run with and without the change on the same
  sitting (the machine drifts 84–104 fights/s day to day). Only one change
  cost anything: recording each show score's cards inside `buildEvents`
  slowed sims ~20%, because the AI scores every candidate discard
  against every unseen starter through it. Moving the card work into a
  separate pass used only by the real show brought it back to no cost.
- **Mod triggers** live in a mutable record the immutable combat state's
  copies share (`CombatState.modTriggers`). A trigger during a piece's
  fire rides on that fire; the rest become timeline beats. Hooks note a
  Mod only when it actually changes something.
- **The engine mutates one state in place between pauses,** so each
  frame the UI gets is a prototype-keeping deep copy: new identities are
  what make Svelte redraw.
- **Layout drift had small causes:** an empty pile row shrinking, a log
  ticker wrapping, a long ticker line widening the page, and a callout
  drawn only on the table while turns fired during the show.
- **The preview's screenshots lag the page,** so fast animations were
  verified from the DOM (computed styles, positions, a sampling loop) and
  long-tail layouts (8-card counts) by filling the pile with copies.
