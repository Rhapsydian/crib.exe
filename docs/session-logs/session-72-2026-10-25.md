## Problem-solving notes

- **Random draws don't promise variety:** a 13-Directive pool still
  repeated within a week; a shuffled deck per cycle (with a boundary
  swap) does.
- **Gross, not net:** Data earned and spent settle between nodes with the
  Shop's costs noted, so spending isn't netted against earning (a test
  checks earned − spent = Data left).
- **Find every 31:** an audit found the limit in pegging, the AI's risk
  counts, the coach's threats and wording, the table, the hand and the
  log; thirty-one Mods follow automatically through the scoring event.
- **Mirror tests separate bugs from effects:** Turncoat Crib cost 3-5
  points a fight (evening out a skilled player's crib edge), not a bug.
- **Check the right exit code:** a commit went in with a failing test
  because the command checked a grep; later commits gate on the tests.
- **Overwrite vs adjust:** a Glitch that set "pairs score 1" erased Pair
  Fold's upside; adjusting on top keeps both.
