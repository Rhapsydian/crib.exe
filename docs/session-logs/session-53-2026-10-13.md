## Problem-solving notes

- **Both Overclock hypotheses were wrong, and that was the finding.**
  Per-turn scoring is skill-flat by construction: a turn fires when
  points fill the gauge, so skill reaches a fight only as turn count.
  Re-routing a bonus through skill-correlated triggers adds no signal.
  The per-hand source does carry skill (12+ points clears 1.54× as often
  at 0.85 v 0.5), but its lumpy payoffs add variance that cancels it.
  Retention is set by **fight length and burst**.
- The first big-hand run overshot power (58–84%) and was confounded;
  the power-matched rerun (53%) gave the clean null.
- An earlier backgrounded command lost its shell variable
  (`S=... && cmd &` backgrounds the assignment too). Fixed by assigning
  on its own line.
- Event Heat initially used encounters.ts's 1-based layer index against
  heat.ts's 0-based tables; caught before the sweep.
