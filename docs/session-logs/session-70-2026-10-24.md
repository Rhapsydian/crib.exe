## Problem-solving notes

- **Record at the answer, not the screen:** LiveRun.answer sees every
  player decision, live or replayed from a save, so the run's rating
  survives a reload for free.
- **One dial, two ends:** a single falloff can't lift weak play and lower
  strong play at once; anchor the one that matters (the simulated player
  as Sharp) and report where the rest land.
- **Coach imports Svelte** (RichText), so calibration ran as a throwaway
  Vitest file rather than a `scripts/` tool.
- **Driving a fight in a hidden pane is slow:** timers throttle; front
  the tab. A CSS transition can also stick there once (the log drawer
  read "open" but stayed off screen); a second try was fine.
- **Content diff by name:** every `name:` in the old branch against the
  current definitions found the 91 new items without per-type id logic.
- **Wrapped markdown:** a bold phrase spanning a line break needs the
  item joined before inline markup.
