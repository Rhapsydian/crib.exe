## Problem-solving notes

- **Both agreed levers measured as weak, and the measurements are the
  finding.** Halving the tracers moved Exploit Heat by about 1 point.
  Switching the strong classes' bridges *off* left them at 26–28%. The
  class gap was **Heat, a second way to lose that only Exploit has**,
  not strength. Session 49's curve was calibrated for one shared way to
  lose.
- **Run victory compounds over four layers:** a 3-point cut per layer
  moved it only ~2 points, so the curve came down 7.5 points in all.
- **The Exploit premium also lifts the pooled cohort,** which moved
  gatekeeper pass rates up 2–5 points and needed a re-tune.
- **Eidolon's starting loadout is sensitive:** Elevated Session in place
  of Steady Drip priced 37.7% victory, and Cache Hit 26.7%.
- **Adaptive Threat responds non-linearly to scale** (growth caps
  against Adaptation); it took three rounds.
- **A stale test:** in "breached, then caught", the toll is checked
  before the gatekeeper's rewards, so a Backup Generator won from that
  fight arrives after the catch. The rule is right; the test now allows
  for it.
