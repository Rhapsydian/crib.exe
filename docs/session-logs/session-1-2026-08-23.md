# Session 1 — 2026-08-23

`/decision-session`, kicking off a brand-new project from scratch (no
prior code or design). General idea going in: a browser-based, hacking-
themed Slay the Spire-style roguelite with combat built on Cribbage.

Worked through the design live, one decision at a time:

- **Combat model**: settled on a shared, adversarial, standard-rules
  2-player Cribbage match (not two players scoring independently) as the
  core loop. Each side has its own initiative gauge, filled by that
  side's own scoring, that resets and grants a turn when crossed.
- **Deckbuilding model**: rejected a StS-style cycling hand of cards in
  favor of a persistent loadout of "subroutines," each with its own
  independent enable-condition (point-count cooldowns, suit-count
  tallies) that fires whenever a turn happens and its condition is met.
  Order in the loadout matters — subroutines can chain/combo — and is
  adjustable as a run progresses. Whether it's ever adjustable mid-combat
  was deliberately left open rather than settled.
- **Map identity**: the run map should read as an actual network diagram,
  not an abstracted path.
- **Run structure**: one run = one target "contract" network, breached in
  nested layers within a single continuous diagram (not separate acts/
  maps), suggested and agreed on this session.
- **Meta-progression**: broad strokes only — subroutine unlocks, classes
  each specializing in 2 of 4 (not-yet-designed) archetypes, Ascension-
  style difficulty, an in-run passive-item pool.
- **Tech stack**: Svelte + Vite, SVG/DOM rendering, no canvas engine.
- **Name**: **crib.exe**, domain `cribexe.com` confirmed available via
  live domain-availability research (instantdomainsearch.com), alongside
  ruled-out alternatives (`cryptopeg.com`/`skunkware.com`, aftermarket-
  only) and unused backups (`cribbagecrack.com`, `pegbreach.com`).

Produced `DESIGN.md`, `BACKLOG.md`, `README.md`, and this project's own
`.claude/dev-session.md` override (matching glyphrogue/glyphkeep's
live-decision-resolution convention). `git init` only — nothing committed
yet.
